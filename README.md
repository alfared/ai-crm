### Backend

- Node.js
- NestJS
- TypeScript
- PostgreSQL

### Frontend

- React
- Vite

- Docker
- Docker Compose

- Redis
- Mailpit

## Requirements

- Node.js 22+
- pnpm
- Docker
- Docker Compose

## Start infrastructure
