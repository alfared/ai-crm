# AI CRM

AI-powered CRM pet project built with NestJS, Node.js, TypeScript and React.

## Technology stack

### Backend

- Node.js
- NestJS
- TypeScript
- PostgreSQL
- Prisma
- Redis
- BullMQ

### Frontend

- React
- Vite
- TypeScript
- TanStack Query
- React Router
- Tailwind CSS

### Infrastructure

- Docker
- Docker Compose
- PostgreSQL
- Redis
- Mailpit

## Requirements

- Node.js 22+
- pnpm
- Docker
- Docker Compose

## Start infrastructure

```bash
docker compose up -d
```
